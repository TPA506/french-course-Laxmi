# Cours de Français A1 — Bilingual French/English Grammar Course

**Français** : Cours complet de grammaire française niveau A1 (grand débutant), bilingue français/anglais, avec des notes en népalais (marquées par `*`) pour les points difficiles.

**English**: Complete A1-level French grammar course, bilingual French/English, with Nepali notes (marked with `*`) for tricky points.

## 🔊 Audio / Audio
👉 [**Cliquez ici pour écouter les leçons**](audio/player.html)

Ouvrez `audio/player.html` dans un navigateur pour écouter chaque phrase française lue à voix haute (synthèse vocale du navigateur, voix française `fr-FR`). Aucune connexion internet requise après le premier chargement (utilise l'API `SpeechSynthesis` intégrée au navigateur).

⚠️ Note : la qualité de la voix dépend du navigateur et du système (Chrome/Edge ont généralement de meilleures voix françaises que Firefox).
